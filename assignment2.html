Project Introduction

For Assignment 2, I developed six parallel prototypes for my browser-based audio instrument, Loop Together.

The project is designed for collaborative and social music creation. It uses looping and sampling as its extended technique and is intended for general users who may not have experience with professional music software.

For this assignment, I explored two areas of interaction design: Looping Interaction and User Feedback. Each version changes a specific design choice while keeping the overall project purpose consistent.

Area 1 — Looping Interaction

Looping and sampling is the extended technique used in my project. This area explores three different ways users might create and understand repeating sound.

The purpose is to investigate how interaction design can make repetition and timing understandable without requiring music production knowledge.

PROTOTYPE 1A

Button Loop

This prototype uses familiar Record, Stop Recording, Play Loop and Stop controls. I chose traditional buttons because most users already understand common media controls.

Purpose

This version explores whether a very simple control system can make looping accessible to first-time users.

Design Question

Is a traditional button-based interface clear enough for users who have never used an audio instrument before?

PROTOTYPE 1B

Circular Loop

This prototype represents the loop visually as a circle divided into eight beats. The active beat moves around the circle while the sample repeats.

Purpose

This version explores whether visualising repetition can help users understand the structure and timing of a loop.

Design Question

Does a circular visual representation make looping and timing easier to understand?

Open Prototype
PROTOTYPE 1C

Step Loop

This prototype uses an eight-step sequence. Users can activate or deactivate each step and decide when a recorded sample should play.

Purpose

This version explores whether direct interaction with individual beats creates a more creative and musical experience.

Design Question

Does step-based sequencing make looping feel more expressive and interactive?

Area 1 Discussion

The three prototypes explore different levels of control. Button Loop focuses on simplicity and familiarity. Circular Loop focuses on visualising repetition. Step Loop focuses on direct rhythmic control.

The differences are not only visual. They change how the user understands the relationship between sound, time and repetition.

Area 2 — Feedback Design

The second design area explores how the instrument responds to user actions. Because Loop Together is designed for people without professional audio experience, users need to understand what the system is doing.

Important states include waiting, recording, listening, playing and stopping. The following prototypes communicate these states in three different ways.

PROTOTYPE 2A

Visual Feedback

This prototype represents microphone activity using a moving audio level and a pulsing shape. Louder input creates a larger visual response.

Purpose

This version explores whether visual response can communicate recording activity clearly without requiring long instructions.

Design Question

Can users understand microphone activity through visual feedback without needing detailed written instructions?

Open Prototype
PROTOTYPE 2B

Text Feedback

This prototype guides the user through the interaction with short messages such as “Record a sound” and “Your sound is ready”.

Purpose

This version explores whether step-by-step instructions can reduce confusion for beginners.

Design Question

Does step-by-step text guidance make the instrument easier to learn?

Open Prototype
PROTOTYPE 2C

Expressive Feedback

This prototype transforms microphone sound into animated visual movement. The feedback is designed to be both functional and playful.

Purpose

This version explores whether animated feedback can make users feel that sound is directly connected to visual movement.

Design Question

Does expressive animation make the instrument feel more playful and musical?

Open Prototype

Area 2 Discussion

Visual Feedback communicates through movement and changing visual states. Text Feedback communicates through direct written instructions. Expressive Feedback combines functional response with playful animation.

These variations explore how much explanation users need and whether feedback should primarily be informational or expressive.

Relationship Between the Two Areas

The two design areas investigate different parts of the same user experience.

Looping Interaction asks: How should users control sound?

Feedback Design asks: How should the instrument respond to those actions?

Together, they explore the relationship between: Action → Sound → Feedback → Understanding.

Peer User Testing

The six prototypes will be used during peer user testing. The purpose of the testing is to understand how users respond to different interaction models and feedback strategies.

Suggested Testing Questions

  1. Which looping prototype was easiest to understand?
  2. Which prototype made the repeating rhythm clearest?
  3. Which looping prototype felt most creative or enjoyable?
  4. Which feedback prototype was easiest to understand?
  5. Did you understand when the instrument was active and responding to you?
  6. Which feedback style felt most engaging?
  7. What part of the instrument was confusing?
  8. What would you change or improve?
  9. Which elements would you combine in a final version?

Next Step
